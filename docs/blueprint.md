# **App Name**: LearnJS

## Core Features:

- Interactive Roadmaps: Interactive roadmap display: Present the learning paths for full-stack, front-end, and back-end JavaScript development in a clear, visual format. Make use of accordions or expandable sections to present the information.
- Curated Content: Content display: Display curated Javascript articles, tutorials, and documentation, fetched from public sources such as the official Javascript documentation or other well known blogs.
- AI Learning Path Tool: AI-powered learning path suggestions: Suggest a learning path based on the user's experience level and goals. The tool uses generative AI to provide suggestions, so it will suggest when the user should learn different topics
- About Section: About page: Explain the app's mission, how to use it, and where the content comes from.
- Profile Dashboard: Profile page: Display the name, user type and account settings in a dashboard-style view.

## Style Guidelines:

- Primary color: Teal (#008080) for a sense of growth and knowledge.
- Secondary color: Light gray (#F0F0F0) for clean backgrounds.
- Accent: Electric Blue (#7DF9FF) for interactive elements.
- Clean, modern sans-serif fonts for readability.
- Use minimalist icons for roadmap categories and content types.
- Clean and structured layout with clear visual hierarchy.
